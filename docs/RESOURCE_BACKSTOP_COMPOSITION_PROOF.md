# Resource backstop composition proof

This review branch adds a transactional synthetic fixture for current main migrations 0028 and 0031. It exercises planning allocation and the exclusive-resource storage constraint together, using two tenants, two independent crews, service capacity two, and one capacity-one resource. The fixture verifies a sealed first allocation, rejection of a direct overlapping reservation by the named exclusion constraint, rejection of a cross-tenant carrier, absence of second-allocation side effects, and successful allocation after the first group is released. It rolls back its transaction.

The fixture is registered in the database CI job after the existing backstop suite. It does not change a migration or production code. Its successful local PostgreSQL run proves only sequential composition; concurrent transaction ordering, PostgreSQL 16 CI, hosted Supabase behavior, and release acceptance require separate evidence. The test uses synthetic identities and no provider credentials or live data.
