# Combined planning allocator: reviewed design boundary

This increment is intended to turn an existing stored draft into one temporary planning group containing service capacity, every linked resource quantity, and every member of an explicitly selected crew. The database resolves service, interval, availability, eligibility, buffers, capacity and expiry. The caller supplies only trusted actor/tenant/booking/crew identity and target generation. It does not confirm bookings, collect money, create worker jobs or expose hosted authentication.

The first supported resolver is explicitly UTC-only with minute precision, bounded source sets, one covering availability window and one covering worker shift. Unsupported timezones, ambiguous schedules and excessive candidate sets fail closed. International/DST schedules remain a required later W4 capability. Source table and group fences are deliberately coarse; this candidate is not a throughput certification.

A successful new generation must seal all service/resource/worker carriers with one expiry or roll back entirely. Exact retries preserve keys and expiry. Terminal or expired-held retries return minimized nonusable history before current scheduling resolution. Replacement keeps the stable group identity and immutable manifests; a resource removed in generation2 and restored in3 reuses its released generation1 carrier without adopting unrelated rows. Financial associations remain prohibited by0027.

Construction may temporarily defer only public.group_final and public.allocation_head_current_generation, then must force those same constraints IMMEDIATE before a successful mutation receipt. Triggers are never disabled; failures are not converted to success. The successful mutating call intentionally leaves those named constraints immediate. The dedicated caller still validates all constraints before COMMIT.

Timing checks require a trusted dedicated caller to configure statement and lock timeouts in separate commands before invocation. Reading a timeout setting cannot prove a timer was armed for an already-running outer statement. Local supported-protocol tests must establish actual waits and cancellation; an externally bounded wrong-shape test documents this limitation. Transaction-wide deadlines, uncertain COMMIT handling, restricted logins and genuine hosted session authentication remain separate deployment/transport gates.
